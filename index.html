Plain answers

Before it meets your counter.

What if my product is not one of the six?+

You can still sell it. Add it to inventory and tap its button on the bill. There is no barcode scanning or billing search yet; the scrolling product strip needs work for a large catalogue.

What if the camera gets it wrong?+

Remove, add or adjust items before saving. The report records corrections. It is not a measured camera accuracy score.

What if the internet drops?+

You cannot save bills or stock changes without internet today. Records are stored in a cloud database. There is no offline billing mode.

Does it handle udhaar and loose items?+

Yes. Put a bill on a customer’s udhaar and record payments later. For loose items, type the weight in grams. There is no connected weighing scale.

Does it take payments?+

No. Record the cash or UPI you have received. JonaRu does not collect or verify money.

Can it read my vendor bills?+

Upload a PDF or photo and review a filled draft. Only sample English invoices have been tested. Real bills may need more corrections; you check every field before saving.

Does it do GST invoices?+

No. The current prototype does not provide GST invoicing.

What device do I need?+

A camera-equipped device, a browser, internet and HTTPS for camera access. The final pilot setup is not decided. Raspberry Pi performance and physical receipt printing are untested.

Is video stored? Where does my data go?+

The current vision server has no video-recording feature. Pictures go to the vision server for recognition; shop records go to a cloud database. We will confirm hosting, access and data handling before a pilot.

How much does it cost?+

Pricing is not set yet. We will discuss scope and any cost before you decide. A demo request is not a purchase.

Does the website language change the app?+

No. The selector changes this page only. Product screens and invoice reading are in English.
